# 📊 Data Visualization

Interactive dashboards and charts built with Plotly, Matplotlib and Seaborn.

## Highlights

- **Interactive Plotly charts** - hover tooltips, zoom and pan out of the box
- **Dashboards** - lightweight web apps for live data exploration
- **Static reports** - publication-ready Matplotlib and Seaborn figures
- **Notebook stories** - narrative walkthroughs of what the data shows

## 🧰 Stack

- **Plotly** & **Plotly Express** - interactive charting
- **Dash** - dashboard apps
- **Matplotlib** & **Seaborn** - static analysis and statistical plots
- **Altair** - declarative visualization grammar
- **Pandas** - data wrangling behind the visuals

## 🚀 Getting Started

```bash
git clone https://github.com/mavispatrick/Data-Visualization.git
cd Data-Visualization
pip install -r requirements.txt
jupyter notebook
```

## 🎨 Principles

1. **Clarity first** - a chart should answer one question
2. **Consistent color** - a palette that means the same thing everywhere
3. **Accessible by default** - readable contrast, no color-only encoding
4. **Label everything** - axes, units, and what the line actually means
